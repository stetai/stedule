# Contributing to stedule

Thank you for your interest in contributing to stedule.

## How to contribute

1. Fork the repository and create your branch from `main`.
2. Name your branch clearly, for example `feature/add-calendar-view` or `fix/login-bug`.
3. Make small, focused changes.
4. Commit with clear messages following the pattern: `type: short description`.

## Reporting issues

- Open an issue if you find a bug, have a feature request, or need clarification.
- Include steps to reproduce the problem, expected behavior, and actual behavior.
- Add screenshots or logs when relevant.

## Pull request process

- Submit a pull request against `main`.
- Describe what the change does and why it is needed.
- Link related issues if applicable.
- Keep changes scoped and avoid unrelated edits.

## Code style

- Follow existing project conventions for naming, formatting, and structure.

## Review and merge

- I will review your PR and may request changes.
- Address review feedback promptly.
- Once approved, the PR can be merged by me.

## Thank you

Your contributions help improve stedule for everyone. We appreciate your help and welcome your ideas.
